WORK BREAKDOWN : FOR HELPDESK LITE 

**1\. PROJECT** 

HelpDesk Lite — Internal Support Ticketing Workspace 

**2\. OBJECTIVE** 

Break the PRD's functional requirements into epics, user stories, and tasks that the team can use for planning and execution 

**3\. EPICS (5)** 

* Request Submission & Management  
* Assignment & Support Workflow  
* Request Communication & Resolution  
* Manager Visibility & Workload  
* Authentication, Roles & Access

**4\. EPIC SPOTLIGHT — REQUEST SUBMISSION & MANAGEMENT** 

Story : As an employee, I want to submit and track my support request so that I can clearly communicate my issue and know its current status.

**5\. TASKS** 

* Design the request creation flow.  
* Build the request submission form.  
* Implement request validation.  
* Generate a unique request ID.  
* Display submitted requests in the employee request list.  
* Build the request details screen.  
* Display current request status and ownership.

**6\. SAMPLE ACCEPTANCE CRITERIA** 

* Employee can submit a support request successfully.  
* Required fields are validated before submission.  
* Each request receives a unique identifier.  
* Submitted requests appear in the employee's request list.  
* Employee can open a request and view its details.  
* Current status is clearly displayed.  
* Current owner is visible when assigned.  
* Invalid or incomplete requests cannot be submitted.

**7\. EXPECTED RESULT** 

All necessary requirements for HelpDesk Lite have been broken down into epics, user stories, tasks, and acceptance criteria, along with any pending issues to ensure safe progress into the Initial Execution Plan and Sprint Planning.
